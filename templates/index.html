Core Technologies

What's under the hood

🔤

NLP Pre-processing

Custom tokenizer with clinical distress lexicon, word-boundary regex, and TF-IDF feature extraction across 250 dimensions.

🧬

TextCNN1D

Multi-kernel 1D Convolutional Network with kernel sizes [2,3,4] fused with TF-IDF branch. Dual-head: Risk + Emotion classification.

⚡

GAN Augmentation

Feature-space Generator + Discriminator trained on high-risk minority class samples. Boosts rare class recall by 8.9% F1.

📊

Dynamic Risk Score

Calibrated composite score: P(Low)×15 + P(Medium)×55 + P(High)×92, with clinical override for crisis-keyword detection.
